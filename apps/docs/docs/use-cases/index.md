# 🧭 Use cases

The user, admin and appliance guides cover what Sneakers-PAM does, one feature at a time. These
pages show how a team actually puts it to work — a specific setup, the folders and rules behind
it, and why it's built that way.

- 🤖 **[A vault for AI agents](./agent-vault.md):** a hub of coding agents and automated tools
  that all need credentials, with the vault as the one place those credentials live and the MCP
  server as how the agents reach them.

More use cases will be added here as they're written up; each one is a real, working setup, not a
hypothetical.
